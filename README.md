# Pwallet Desktop App

## Project Overview
Pwallet Desktop App is a finance management application built using Electron and Node.js, designed to operate seamlessly on Windows. It provides users with features to manage their digital wallets and financial transactions effectively, utilizing interactive charts and data manipulation tools.

## Installation
To get started with Pwallet Desktop App, you'll need Node.js and npm installed on your machine. Follow the steps below to set it up:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/pwallet-desktop-app.git
   cd pwallet-desktop-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the application:**
   ```bash
   npm start
   ```

## Usage
After successfully starting the application, you can use the following features:

- **View Wallet Balances:** Check your digital wallet balances in real-time.
- **Generate Reports:** Use charts to visualize your spending patterns and wallet distributions.
- **Manage Transactions:** Add, edit, or delete transactions to keep your finances up-to-date.

## Features
- **Cross-platform compatibility:** Built using Electron, it runs seamlessly on Windows.
- **Interactive Data Visualization:** Integrated with Chart.js for visual representation of financial data.
- **Date Management:** Utilizes date-fns for handling dates and times easily.

## Dependencies
This project has several dependencies listed in `package.json`. The main ones include:

- **electron:** A framework for building cross-platform desktop applications.
- **chart.js:** A flexible JavaScript charting library for data visualization.
- **date-fns:** A modern JavaScript date utility library for manipulating dates.

You can view the full list of dependencies by checking the `package.json` file.
